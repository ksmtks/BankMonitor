# BankMonitor (입금 모니터)

카카오뱅크 입금 알림을 읽어 저장하고, 입금 즉시 알림과 일간/주간/월간 요약 보고서를 텔레그램으로 보내는 안드로이드 앱.

## 기능
- 카카오뱅크 앱의 `입금 N원 / 보낸이 → 계좌(끝4자리) 잔액 N원` 알림 파싱 (NotificationListenerService)
- 앱 안에서 입금 내역 조회(길게 누르면 삭제), 일/주/월 보고서 조회·텔레그램 전송
- 텔레그램 토큰/Chat ID는 앱 설정 탭에서 입력 (코드에 하드코딩 없음)
- 보고서 자동 전송: 일간/주간/월간 각각 켜고 끄기, 발송 시각(주간은 요일, 월간은 일자 포함)을 설정 탭에서 지정. 폰이 꺼져 있었으면 다음 실행 때 밀린 최신 보고서를 전송

## APK 받기
GitHub Actions가 push 마다 빌드합니다. 저장소의 **Releases → Latest APK → BankMonitor.apk** 를 폰에서 받아 설치하세요.

## 처음 사용
1. 설정 탭에 봇 토큰과 Chat ID 입력 → 저장 → 테스트 전송
2. "알림 접근 설정 열기"에서 입금 모니터 허용 (Android 13+는 '제한된 설정 허용' 필요할 수 있음)
3. 배터리 사용 '제한 없음' 권장

## 빌드
JDK 17 + Gradle 8.9: `gradle assembleDebug`
